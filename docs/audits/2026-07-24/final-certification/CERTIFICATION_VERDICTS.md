# Dictámenes técnicos

## Base: GO condicionado

No quedan S0/S1 de código conocidos en Presentación, Control, Audience, Quiz,
PWA o Multimedia. La suite completa, TypeScript, ESLint, build y stack Docker
han aprobado. LiveKit no condiciona la salud de Base.

La condición para elevarlo a **GO** es completar y archivar:

- dos pasadas en Windows 11+NVDA, iPhone+VoiceOver y Android+TalkBack;
- certificado público/HSTS y prueba del dominio final;
- restauración operativa y apagado limpio en la instalación;
- control de advisories autorizado.

Cualquier bypass de Controlado, acceso offline protegido sin admisión, pérdida
de foco obligatoria WCAG 2.2 A/AA o política obsoleta revoca este dictamen.

## Live Audio: NO-GO temporal

El código y el stack local superan sincronización versionada, overlay E2E,
recordingEpoch, tokens, readiness real e ICE/TCP. Sin embargo, faltan evidencias
obligatorias que definen su aptitud en producción:

- datos móviles reales y redes con UDP bloqueado;
- tres Controles y 50 Audience;
- pérdida, duplicación y reorden de paquetes;
- reconexión, sucesión, DDNS e IP dinámica reales;
- pruebas físicas VoiceOver/TalkBack/NVDA;
- TURN/TLS cuando las redes objetivo no puedan alcanzar UDP o TCP 7881.

Live Audio no puede anunciarse como apto para producción hasta completar esa
matriz sin divergencias, pérdida de mensajes, fuga nominal, confirmación de
grabación obsoleta ni bypass de permisos.

## Naturaleza del dictamen

Estos resultados evalúan una versión concreta del software y la topología
Docker Compose de instancia única. No certifican una organización concreta, su
base jurídica, su grabador externo, su red, sus políticas ni sus proveedores.
