# Información organizativa adicional

Esta plantilla muestra el contenido opcional que una instalación puede montar
como `privacy.local.md`. Sustituya este texto por la política aprobada por la
entidad operadora.

## Finalidades y conservación

- Describa las finalidades concretas del tratamiento.
- Indique los periodos de conservación aplicables.
- Explique si existen encargados del tratamiento o transferencias.

## Derechos y contacto

Explique cómo ejercer los derechos aplicables. Los datos estructurados mínimos
del operador y el contacto se configuran mediante las variables documentadas en
`.env.example`.

[Consulte la política publicada por el operador](https://example.org/privacy)

El archivo local admite títulos, párrafos, listas y enlaces HTTP, HTTPS,
`mailto:` o rutas relativas. El HTML incrustado no se interpreta.
